# Support

Thanks for taking a look at Page Builder. It's a commercetools Labs project: reference code we
share openly because we think it's useful, and we're glad when people pick it up.

## What to expect

This repository is shared as-is and isn't covered by commercetools support. That means we can't
promise replies, fixes, or any particular response time, and we can't guarantee it fits your
project. Issues and pull requests are very welcome, and we'll look when we can.

## If you need something

- **Fork it and adapt it.** The code is MIT-licensed, so take it where your project needs it to go.
- **Ask the community.** Questions about how it works are great discussion topics.
- **Use commercetools support for the platform itself.** For the commercetools APIs, the
  Merchant Center, or Connect, your normal support channel is the right place.
